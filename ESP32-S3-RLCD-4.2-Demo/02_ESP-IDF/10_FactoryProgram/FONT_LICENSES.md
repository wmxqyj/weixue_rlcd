# Font attribution

The generated LVGL bitmap font `lv_font_noto_sans_sc_18.c` uses glyphs from
**Noto Sans CJK SC**, provided by the Noto Fonts project under the SIL Open
Font License 1.1.

- Project: https://github.com/notofonts/noto-cjk
- License: https://openfontlicense.org/

Only the glyph bitmaps required by this embedded user interface are included
in the firmware source. The original OpenType font is a local build tool input
and is not stored in this repository.
